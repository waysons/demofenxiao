# demofenxiao

三三拼团分销模式静态模拟网站，支持七人成团、每侧独立结算管理奖、八层复购及关系树展开/收起。

## 文件

- `index.html`：网站入口。
- `assets/styles.css`：原页面自定义样式。
- `assets/simulation-engine.js`：结算、复购资格和删除重算逻辑。
- `assets/simulation-ui.js`：页面交互与收益展示。

无需安装依赖或构建，保留全部文件即可运行。Tailwind CSS 继续使用原页面的 CDN，需要联网加载。

## 当前模拟规则

- 每位新增直推订单均发 199 × 20% = 39.80 元直推奖。
- 本人、前两名直推及两人各自的前两名直推，组成 1+2+4 七人团后，结算拼团奖 29.85 元，每人仅一次。单侧多邀和扶持区成员不能补位。
- 前两名直推各自邀齐两人时，分别给直接上级结算管理奖：每席 29.85 × 8% 四舍五入为 2.39 元，两席 4.78 元，两侧共 9.56 元。每侧仅发一次，不以七人成团为前提；扶持区成员邀齐两人不向该上级发管理奖，也不向更高层分摊。
- 第三位及之后属于扶持区，额外发订单奖 19.90 元，不触发拼团奖、管理奖或祖先分摊。
- 每位成员以本人以下的最深推荐代数计算八层，到期暂停其邀请；复购 199 元恢复，以复购时层数为新起点继续八层。复购保留团队与历史收益，不新增成员或重复发奖；删除重算保留已支付复购的资格起点。
- 包括根节点在内的所有分支可独立收起/展开，也可统一控制；节点用对应颜色显示贡献公式，拼团奖在主节点的拼团区虚线框内单独展示，每个框只保留一个居中的区域名称。

## 验证

运行 `node --test tests/reward-triggers.test.cjs`，验证拼团奖与管理奖的独立触发、归属、不重复结算及删除重算。
