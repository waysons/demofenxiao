# demofenxiao

三三拼团分销模式静态模拟网站，支持七人成团、成团复投滑落、市场动态排位、平级团长管理奖及关系树展开/收起。

## 文件

- `index.html`：网站入口。
- `assets/styles.css`：原页面自定义样式。
- `assets/simulation-engine.js`：结算、成团复投滑落、市场重排和删除重算逻辑。
- `assets/simulation-ui.js`：页面交互与收益展示。

无需安装依赖或构建，保留全部文件即可运行。Tailwind CSS 继续使用原页面的 CDN，需要联网加载。

## 当前模拟规则

与后端 `distRewardRules.settleCountedJoin` 一致，单价仍用 199 元模拟支付。默认比例：直推 25% / 拼团 20% / 订单 10% / 管理 8%（操作中心可改，只影响之后新订单）。扶持区直推满 2 人时上级拿订单奖（199×10%=19.90）。

- 操作中心顶部固定「滑落版本」（6 种）与「新增下线」；邀请弹窗支持**每层人数 × 向下层数**批量生成（合计上限 100）。
- 七人团只计本人 + 前两名直推各自整棵下级树。满 7 人且真人直推满 2 才发拼团奖。真人直推满 3 即为团长。
- 席位按市场动态：有裂变优先，同档入团时间新→旧。
- 订单奖：直推 1→2 时向上最多 8 层；落在入团序第 3+ 分支才发；支线根已是团长则截流。
- **仅标记** / 模拟购买入团 / 改时间：同前。
- **三三复制商业V2**：第 3 人扶持区；第 4 人起 L/R DFS 滑落帮扶；计团复投给树上挂点发帮扶直推奖并计团长席 +1（复投点本人零收益）。
