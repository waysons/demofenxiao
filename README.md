# demofenxiao

三三拼团分销模式静态模拟网站，支持七人成团、八层复购及关系树展开/收起。

## 文件

- `index.html`：网站入口。
- `assets/styles.css`：原页面自定义样式。
- `assets/simulation-engine.js`：结算、复购资格和删除重算逻辑。
- `assets/simulation-ui.js`：页面交互与收益展示。

无需安装依赖或构建，保留全部文件即可运行。Tailwind CSS 继续使用原页面的 CDN，需要联网加载。

## 当前模拟规则

- 每位新增直推订单均发 199 × 20% = 39.80 元直推奖。
- 本人、前两名直推及这两人各自的前两名直推，组成 1+2+4 七人团；团长仅首次成团结算拼团奖 29.85 元和管理奖 2.39 元。
- 第三位及之后属于扶持区，额外发订单奖 19.90 元，不触发拼团奖、管理奖或祖先分摊。
- 每位成员以本人以下的最深推荐代数计算八层，到期暂停其邀请；复购 199 元恢复，以复购时层数为新起点继续八层。复购保留团队与历史收益，不新增成员或重复发奖；删除重算保留已支付复购的资格起点。
- 包括根节点在内的所有分支可独立收起/展开，也可统一控制；四奖明细独立控制。

## GitHub Pages

在仓库 **Settings → Pages** 中选择 **Deploy from a branch**，分支选择 `main`，目录选择 `/(root)` 后保存。

发布成功后访问：https://waysons.github.io/demofenxiao/

## 数据说明

仅为静态模拟，无真实扣款。数据保存在每位访客当前页面的内存中，不会与其他访客同步，刷新后清空。
