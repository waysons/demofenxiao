# demofenxiao

三三拼团分销模式静态模拟网站，支持七人成团、成团复投滑落、市场动态排位、平级团长管理奖及关系树展开/收起。

## 文件

- `index.html`：网站入口。
- `assets/styles.css`：原页面自定义样式。
- `assets/simulation-engine.js`：结算、成团复投滑落、市场重排和删除重算逻辑。
- `assets/simulation-ui.js`：页面交互与收益展示。

无需安装依赖或构建，保留全部文件即可运行。Tailwind CSS 继续使用原页面的 CDN，需要联网加载。

## 当前模拟规则

与后端 `distRewardRules.settleCountedJoin` 一致，单价仍用 199 元模拟支付。

- 每位新增直推订单均发实付 × 20% = 39.80 元直推奖。
- 七人团只计本人 + 前两名直推各自整棵下级树。满 7 人且真人直推满 2 才发实付 × 15% = 29.85 元，每人仅一次。本人第 3 名及以后的分支不计入本人的团。
- 真人直推满 3 即为团长，与是否七人成团无关。双方都是团长且下级已经拿到拼团奖后，给直接上级结算该拼团奖 × 8% = 2.39 元，每名直推仅一次。下级先达标会等到上级也达标。
- 席位按市场动态：有裂变（名下 ≥1 已入团真人）优先，同档按入团时间新→旧。新单按当前席位结算；已记流水日常不回改，删除分支重放除外。
- 订单奖：某人直推从 1→2 时向上最多 8 层查找；落在扶持区（第 3 名及以后）才发 10%；付款前该上级或分支根已是团长则停止。在「推荐人必须已入团 + 团长=直推≥3」下，能进扶持区的上级付款前通常已是团长，故订单奖与后端口径一致、实际几乎不触发（有回归用例锁定）。
- 县 / 市 / 省代理按之后的新订单发放实付的 3% / 6% / 9%。八层只限制订单奖查找，不暂停邀请；成团复投是自动滑落，不是复购门槛。
- **仅标记**：关系树显示「标记」角标，不占左右位、不扣 199、不发奖；推荐人必须已入团。**模拟购买入团**走完整结算，可指定入团时间；已入团改时间仅重排同级（平局用 `joinSeq`），不重发奖。
- 包括根节点在内的所有分支可独立收起/展开；拼团奖在主节点前两名直推的虚线框内展示，管理奖在对应直推节点下方显示。

## 验证

运行 `node --test tests/*.test.cjs`（当前 32 项），覆盖：单链满 7 补第 2 直推成团、市场重排（B3 裂变左移 / joinSeq）、仅标记与模拟入团、推荐人须已入团、平级管理奖、订单奖截断、复投滑落及删除重放（保留 joinedAt 与标记）。
